# Skip Account Picker Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** "Open Google Chat" appends a per-device `authuser=<work email>` hint (asked once via prompt, editable in Settings) so Google skips its account chooser.

**Architecture:** New per-device localStorage key + an `openChatLink()` helper used by the camera-button chat branch; a device-only Settings row for corrections. No published-data changes.

**Tech Stack:** Vanilla JS in faregate.html (+ README note). Manual browser verification.

**Spec:** `docs/superpowers/specs/2026-08-12-authuser-design.md`

## Global Constraints

- Only `faregate.html` and `README.md` change. NO `data.json` change, no new published keys, no `markChanged()`/dirty-badge involvement for the email (device-only state).
- localStorage key exactly `"faregate.chatEmail"`.
- `window.open` stays synchronous inside the click handler.
- Invalid email input toasts exactly `❌ That doesn't look like an email` and stores nothing.
- No push (controller handles).

- [ ] **Step 1: Constant.** Next to the other `LS_*` constants add:

- [ ] **Step 2: Helper.** Add after `updateActionButtons`:

```js
function openChatLink(){
  let email = (localStorage.getItem(LS_CHAT_EMAIL) || "").trim();
  if (!email){
    const v = prompt("Enter your work Gmail once to skip Google's account picker (Cancel to skip):");
    if (v && v.trim()){
      if (v.trim().includes("@")){
        email = v.trim();
        localStorage.setItem(LS_CHAT_EMAIL, email);
      } else {
        showToast("❌ That doesn't look like an email");
      }
    }
  }
  let url = localData.chatSpaceLink;
  if (email){
    url += (url.includes("?") ? "&" : "?") + "authuser=" + encodeURIComponent(email);
  }
  window.open(url, "_blank");
}
```
